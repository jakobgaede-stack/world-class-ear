# World Class Ear

Adaptive Gehörbildung für Dirigenten: Intervalle, Akkorde, Cluster, Setklassen, Akkordfolgen und Modulation,
Fehlerhören (Melodie, Akkord, Bachchoral, Orchestersatz), Balance, Melodie-, Zwölfton- und mehrstimmiges Diktat,
Blattsingen mit Mikrofon, passives Hören mit Partitur, Tageslektion nach Zeitbudget, Statistik, Sync zwischen Geräten.
Web-App ohne Build-Schritt (HTML, CSS, ES-Module). Empfohlen: Chrome auf dem Mac.

Konzept: siehe Konzeptdokument (Claude). Lizenzen der Klänge: `assets/samples/LICENSES.md`, Choräle: `assets/chorales/LICENSE.md`,
Orchesterliteratur: `assets/orchestra/LICENSE.md` (die Haydn-Ausschnitte aus CCARH-Daten sind nicht im Repo und werden nur privat
über den Sync-Server ausgeliefert), Notensatz: VexFlow (MIT, `vendor/VEXFLOW-LICENSE`).
