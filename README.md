# World Class Ear

Adaptive Gehörbildung für Dirigenten: Intervalle, Akkorde, Cluster, Fehlerhören in Originalliteratur, Balance.
Web-App ohne Build-Schritt (HTML, CSS, ES-Module). Empfohlen: Chrome auf dem Mac.

Konzept: siehe Konzeptdokument (Claude). Lizenzen der Klänge: `assets/samples/LICENSES.md`, Choräle: `assets/chorales/LICENSE.md`, Notensatz: VexFlow (MIT, `vendor/VEXFLOW-LICENSE`).
